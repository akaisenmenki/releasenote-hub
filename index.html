Release Note Hub Manual¶

Overview¶

Release Note Hub は、Google スプレッドシートで管理している リリース情報を Web 上で公開するためのサンプルアプリケーションです。

Architecture¶

Release Note Hub は、以下の構成で動作します。

  • Google Sheets: リリース情報の保存

  • Google Apps Script: 公開データを JSON 形式で提供

  • HTML / JavaScript: リリース情報を取得して画面に表示

  • GitHub: ソースコードと変更履歴の管理

  • Ubuntu Server: Web サーバー環境

  • nginx: Web ページの配信

How to Publish¶

  1. Google Sheets にリリース情報を追加します。

  2. Status を Published に設定します。

  3. GAS が公開対象のデータを JSON 形式で返します。

  4. Web ページが GAS からデータを取得して表示します。

Troubleshooting¶

リリース情報が表示されない場合は、以下を確認してください。

  • Status が Published になっているか

  • GAS の Web アプリ URL が正しいか

  • nginx が起動しているか
